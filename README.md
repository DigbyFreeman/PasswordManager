A C++ and QT based password manager. This was a very old project. In its current state, it works, but it's a bit rough around the edges, one day I'll fix it up better. I would recommend that you build/run from QT (Preferably debug mode), and make sure you have SQLite3 for storage and OpenSSL for encryption.

Sadly, when I made this I was not making it for anyone else to see particularly. Because of this, it doesn't have many comments.

Also, when I made this I don't think I fully understood the point of having a headless method to use it. Right now, it's a serious of questions - this defeats the point of having a headless version of the program really. Again, I will change this one day.

Aside from those two points, this was a pretty decent project, and it works fairly well. Can store up to I think 31 characters (although I'm not definite) for a username or password. It has a good GUI I would say, simple, and it works.

When making this, I used char arrays instead of strings, in an effort to have more memory management, as I believed at the time this would make it more secure.
